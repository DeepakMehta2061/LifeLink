# LifeLink

> A simple Flask-based web app connecting drivers and hospitals to facilitate rapid patient transport and coordination.

## Description

LifeLink is a lightweight web application designed to help coordinate drivers, hospitals, and users. It provides simple interfaces for drivers and hospitals to manage availability and for users to request assistance. The project is suitable as a small proof-of-concept or starting point for a logistics/medical transport coordination system.

## Features

- Driver dashboard (templates/driver.html)
- Hospital dashboard (templates/hospital.html)
- User interface (templates/user.html)
- Minimal Python/Flask backend (app.py)

## Tech stack

- Python 3.8+
- Flask (recommended)
- HTML/CSS/JavaScript for frontend
