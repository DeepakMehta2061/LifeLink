LifeLink is a web app that helps coordinate emergencies think of it as a digital bridge between someone who needs help, the ambulance driver, and the hospital.
What problem it solves: Right now in an emergency, someone has to call around, figure out which hospital has space, and hope an ambulance is available. LifeLink automates all of that in one place.
The three people it serves:

Someone reporting an emergency fills in a short form — their name, location, and what happened
A driver gets an alert on their screen and can accept the call
A hospital can see incoming patients and update how many beds they have

What it does automatically:

The moment an emergency is submitted, it finds a free ambulance
It recommends the right hospital based on what kind of injury it is (burn, trauma, etc.) and which hospitals have room
Everyone can see the live status

Built with: Python on the back end (handles all the logic), a simple webpage for the front end (what people see and click), and a database to store everything. Nothing overly complicated it's a focused, practical tool.
